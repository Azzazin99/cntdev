cntdev — เว็บกลุ่มพัฒนาครูและบุคลากรทางการศึกษา สพป.ชัยนาท

เว็บไซต์สำนักงานเขตพื้นที่การศึกษาประถมศึกษาชัยนาท สร้างด้วย SvelteKit deploy บน Vercel ข้อมูล production อยู่ที่ Firebase Firestore

  • Production: https://cntdev.vercel.app
  • GitHub: https://github.com/Azzazin99/cntdev

เอกสาร Tech Stack & Schema

เอกสารเต็ม (แผนที่โค้ด + ข้อมูลเก็บที่ไหน + env vars):

ไฟล์ คำอธิบาย
CONTEXT.md นิยามโดเมน — metadata hub, document link, bulk list ฯลฯ
docs/tech-stack.html เอกสารอ่านหลัก — ตาราง stack, storage schema, code map
docs/data-schema.json แหล่งความจริงแบบ JSON (agent อัปเดตเมื่อเปลี่ยนโครงสร้าง)
docs/cloudflare-setup.html Cloudflare Turnstile + CDN เมื่อมีโดเมน
docs/google-drive-workflow.html PDF ผ่าน Google Drive — วางลิงก์ใน admin
docs/vercel-blob-setup.html ตั้ง Vercel Blob สำหรับอัปโหลดรูปกิจกรรม/บุคลากร

เปิด docs/tech-stack.html ใน Cursor หรือ GitHub ได้ทันที

พัฒนาในเครื่อง

npm install
    cp .env.example .env.local   # แล้วใส่ค่าจริง
    npm run dev

ดูรายการ env ที่จำเป็นใน .env.example

Deploy

git add .
    git commit -m "คำอธิบายการเปลี่ยนแปลง"
    git push origin main

Vercel deploy อัตโนมัติจาก branch main — หลังเปลี่ยน Environment Variables ต้อง Redeploy

โครงสร้างสำคัญ (สรุป)

งาน ที่ไปแก้
หน้าเว็บ / เมนู src/routes/, src/components/
Admin src/routes/admin/+page.svelte
API src/routes/api/
ข้อมูล Firestore/JSON src/lib/server/contentStore.js
Login / session src/routes/login/, src/lib/server/localAuth.js
สไตล์รวม src/app.css

หมายเหตุ: ไฟล์ index.html, admin.html ฯลฯ ใน root เป็นโค้ดเก่า — ไม่ใช่ แอปที่รันบน Vercel (ใช้ src/ แทน)

การอัปเดตเอกสาร

เมื่อเพิ่ม route, API, env, หรือที่เก็บข้อมูล — อัปเดต docs/data-schema.json และ docs/tech-stack.html ด้วย (ดูกฎใน .cursor/rules/tech-docs.mdc)
