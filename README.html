# 🚀 cntdev (ระบบสารสนเทศกลุ่มพัฒนาครูและบุคลากรทางการศึกษา) เว็บไซต์อย่างเป็นทางการของกลุ่มพัฒนาครูและบุคลากรทางการศึกษา สำนักงานเขตพื้นที่การศึกษาประถมศึกษาชัยนาท (สพป.ชัยนาท) พัฒนาขึ้นเพื่อเป็นศูนย์กลางในการเผยแพร่ข้อมูลข่าวสาร ให้บริการข้อมูลบุคลากร และรวบรวมระบบสารสนเทศที่จำเป็นสำหรับการปฏิบัติงาน 🌐 **Website:** [https://cntdev.vercel.app/](https://cntdev.vercel.app/) ## ✨ ฟีเจอร์หลัก (Features) * 📰 **ระบบข่าวสารและกิจกรรม:** อัปเดตข่าวประชาสัมพันธ์ ภาพกิจกรรม และประกาศที่สำคัญของกลุ่มฯ * 📚 **คลังความรู้และคู่มือ:** แหล่งรวบรวมและดาวน์โหลดคู่มือการปฏิบัติงาน (เช่น คู่มือ OBEC Award) ระเบียบ และคำสั่งต่างๆ * 🏆 **คลังเกียรติบัตรออนไลน์:** ระบบสำหรับสืบค้นและดาวน์โหลดเกียรติบัตร * 📝 **ศูนย์รวมแบบฟอร์ม:** ดาวน์โหลดแบบฟอร์มคำร้องและเอกสารที่จำเป็นต่างๆ * 👥 **ข้อมูลบุคลากรและโครงสร้าง:** แสดงข้อมูลบุคลากร อำนาจหน้าที่ และช่องทางการติดต่อ * 🔐 **ระบบจัดการบุคลากร (HRMS):** รองรับระบบทะเบียนประวัติและการเข้าสู่ระบบสำหรับเจ้าหน้าที่ ## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack) * **Framework:** Next.js * **Deployment:** Vercel ## 💻 การติดตั้งและทดสอบรันในเครื่อง (Getting Started) ### สิ่งที่ต้องมี (Prerequisites) * Node.js * npm, yarn, pnpm หรือ bun ### วิธีการติดตั้ง (Installation) 1.
