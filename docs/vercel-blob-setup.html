ตั้งค่า Vercel Blob สำหรับอัปโหลดไฟล์

โปรเจกต์: cntdev · Production: https://cntdev.vercel.app

PDF ข่าว: อัปโหลดผ่าน Vercel Blob จากแท็บข่าวใน admin (สูงสุด 20 MB) — หรือวางลิงก์ Google Drive แทนได้

PDF อื่นๆ (คู่มือ, ความรู้, แผน, แบบฟอร์ม): ใช้ Google Drive — ดู google-drive-workflow.html

รูปภาพ: กิจกรรมและบุคลากรอัปโหลดผ่าน Vercel Blob (สูงสุด 5 MB ต่อรูป)

ทำไมใช้ Vercel Blob

  • Firestore เก็บข้อความและลิงก์เอกสาร
  • Vercel Blob เก็บ PDF ข่าว รูปกิจกรรม และรูปบุคลากรจาก admin
  • ไม่ต้องตั้ง CORS แบบ Firebase Storage

ขั้นตอนใน Vercel Dashboard

  1. เปิด Vercel Dashboard → เลือกโปรเจกต์ cntdev
  2. แถบซ้าย → Storage → Create Database → เลือก Blob
  3. ตั้งชื่อ store (เช่น cntdev-files)
  4. เลือก Public (รูปต้องแสดงบนหน้าสาธารณะได้)
  5. ติ๊ก Production และ Preview เพื่อ inject env
  6. กด Create — Vercel จะเชื่อม env ให้โปรเจกต์ (เช่น BLOB_STORE_ID และ OIDC)
  7. สร้าง Read-Write Token (จำเป็นสำหรับอัปโหลด PDF ข่าวจาก admin ในเบราว์เซอร์): ใน Blob store → แท็บ Projects → เลือก cntdev → สร้าง / เพิ่ม BLOB_READ_WRITE_TOKEN ให้ Production + Preview (OIDC อย่างเดียวใช้กับ handleUpload ไม่ได้)
  8. Redeploy production หลังเชื่อม store และ token

Local dev

สำคัญ: vercel env pull ธรรมดาดึงแค่ Development (มีแค่ OIDC) — login admin จะล้มเพราะไม่มี ADMIN_PASSWORD

  1. vercel link
  2. vercel env pull .env.local --environment=production
  3. restart npm run dev
  4. เปิด http://localhost:6395/admin — login ด้วย username admin + รหัสที่ตั้งบน Vercel
  5. ลองอัปโหลด PDF ข่าวหรือรูป

อัปโหลดจาก admin ส่งไฟล์ผ่าน API แล้วใช้ put() ฝั่ง server (OIDC บน production) — ไม่ใช้ client token อีกแล้ว

บนเครื่อง dev ไฟล์จะเขียนลง static/ (ยกเว้นมี BLOB_READ_WRITE_TOKEN ใน .env.local)

แก้ปัญหาอัปโหลด

ข้อความ errorแก้
Failed to retrieve the client token ยังไม่มี BLOB_READ_WRITE_TOKEN — สร้าง Read-Write Token ใน Blob store แล้ว redeploy (ดูขั้นตอนด้านบน)
ไฟล์ใหญ่เกิน 4.5 MB สำหรับอัปโหลดแบบ server PDF ข่าวสูงสุด 20 MB ต้องมี BLOB_READ_WRITE_TOKEN เพื่ออัปโหลดตรงจากเบราว์เซอร์

แก้ปัญหา 404 ตอนเปิดอ่าน

อาการสาเหตุ / แก้
เปิดอ่านแล้ว 404 บน cntdev.vercel.app อัปบนเครื่อง dev แล้วไฟล์อยู่แค่ใน static/ — ต้องอัปใหม่บน production เมื่อ Blob ตั้งแล้ว (ลิงก์จะเป็น *.public.blob.vercel-storage.com) หรือใช้ลิงก์ Google Drive
ลิงก์เป็น assets/documents/... แล้ว 404 path ต้องขึ้นต้นด้วย / — โค้ดแก้แล้วใน resolveDocumentOpenUrl; ข่าวที่อัปก่อนหน้านี้อาจต้องแก้ไขรายการแล้วอัป PDF ใหม่
ลิงก์ Blob แต่ 404 ตรวจว่า store เป็น Public และ redeploy หลังสร้าง Blob; ลองเปิด URL ในแท็บใหม่ตรงๆ
