# ADR-0002: Admin tab order matches public navbar

## Status

Accepted

## Context

แท็บใน `/admin` เคยเรียงข่าว/กิจกรรมก่อน แล้วตามด้วย listTypes เดิม ทำให้ไม่สอดคล้องกับลำดับเมนูสาธารณะบน navbar — ผู้ดูแลสับสนเมื่อหาแท็บ

คลังความรู้มีหน้า `/knowledge` แต่ไม่อยู่ใน navbar (ลิงก์จากหน้าแรก)  
แบนเนอร์มีเฉพาะใน admin

## Decision

เรียงแท็บ admin ตาม navbar แล้วต่อด้วยคลังความรู้และแบนเนอร์:

บุคลากร → อำนาจหน้าที่ → คู่มือ → แผน → ข่าว → กิจกรรม → แบบฟอร์ม → เกียรติบัตร → คลังความรู้ → แบนเนอร์

ค่าเริ่มต้นตอนเปิด `/admin` คือแท็บบุคลากร  
ลำดับเก็บใน `adminNavTabs` ใน `src/routes/admin/+page.svelte`

## Consequences

- ผู้ดูแลจับคู่หน้าสาธารณะกับแท็บแก้ได้เร็วขึ้น
- ถ้าเปลี่ยนลำดับ navbar ต้องอัปเดต `adminNavTabs` ให้ตรงกัน
