อัปโหลด PDF ผ่าน Google Drive (workflow สำหรับ admin)

เว็บ cntdev.vercel.app ไม่รับอัปโหลด PDF โดยตรงอีกต่อไป — ใช้ Google Drive เป็นที่เก็บไฟล์เดียว แล้ววางลิงก์ใน admin

ข้อดี: อัปไฟล์ครั้งเดียว ใช้ลิงก์เดียวกันได้ทั้งบน cntdev และ cnt.go.th

ขั้นตอนสำหรับ admin

  1. อัป PDF ขึ้น Google Drive (โฟลเดอร์ของกลุ่มพัฒนาครูฯ หรือโฟลเดอร์ที่ใช้งานร่วมกัน)
  2. คลิกขวาที่ไฟล์ → แชร์
  3. ตั้งสิทธิ์เป็น ทุกคนที่มีลิงก์ → ผู้ดู (หรือเทียบเท่า)
  4. คัดลอกลิงก์ (รูปแบบ https://drive.google.com/file/d/FILE_ID/view)
  5. เข้า /admin → แท็บข่าวหรือเอกสาร → เพิ่ม/แก้รายการ
  6. วางลิงก์ในช่อง ลิงก์เอกสาร (Google Drive) แล้วบันทึก
  7. บน cnt.go.th ใช้ลิงก์ Drive เดียวกัน (ไม่ต้องอัปซ้ำบน cntdev)

สิ่งที่ยังอัปโหลดบนเว็บได้

  • รูปกิจกรรม — อัปโหลดใน admin (Vercel Blob) หรือวาง URL รูป
  • รูปบุคลากร — อัปโหลดใน admin (Vercel Blob) หรือวาง URL รูป

ตั้งค่า Blob สำหรับรูป: vercel-blob-setup.html

ไฟล์เก่าบน Blob / Firebase Storage

ข่าวหรือเอกสารที่เคยอัปโหลดไฟล์ตรงบนเว็บ — ลิงก์เดิมยังเปิดได้จนกว่าจะแก้รายการเป็นลิงก์ Drive

อาการแก้
กด「เปิดอ่าน」แล้วขอสิทธิ์เข้าถึง ตั้งแชร์ Drive เป็น「ทุกคนที่มีลิงก์」ดูได้
บันทึกไม่ได้ — กรุณาวางลิงก์เอกสาร กรอกลิงก์ในช่องลิงก์เอกสาร (รายการใหม่ต้องมีลิงก์)
ลิงก์ไม่ใช่ Drive ก็ได้ไหม ได้ — ใส่ URL https ใดก็ได้ที่เปิด PDF ได้ (เช่น cnt.go.th)
